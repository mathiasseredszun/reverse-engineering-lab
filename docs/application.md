## Current program information

The [Cyber Verification Program](https://support.claude.com/en/articles/14604842-cyber-verification-program)
provides a verification portal and asks for identity/organization information,
a description of security work and attestations to applicable controls.
Individual applicants can apply for Defense Access on a paid plan; organization
applications follow a separate verification context. Check the live program
documentation before applying, since terms can change.

The [security requirements](https://support.claude.com/en/articles/17202708-cyber-verification-program-security-requirements)
must be reviewed privately. Do not equate a restricted laboratory container with
compliance across an organization. Do not assert controls that have not been
implemented and verified.
